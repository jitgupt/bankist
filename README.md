# Bankist - Minimalist Banking Website

## Overview

**Bankist** is a modern, minimalist banking website showcasing a sleek and user-friendly interface for a fictitious banking application. This project demonstrates modern web development practices using vanilla JavaScript, HTML, and CSS with interactive features and smooth animations.

The site tagline: *"When Banking meets Minimalist"*

## Features

- **Modal Window**: Open account functionality with modal popup
- **Smooth Navigation**: Smooth scrolling navigation between sections using modern DOM APIs
- **Tabbed Interface**: Operations section with interactive tabbed content
- **Menu Animations**: Hover effects on navigation menu with opacity transitions
- **Sticky Navigation**: Intelligent sticky header using Intersection Observer API
- **Responsive Design**: Mobile-friendly layout with modern CSS
- **Interactive Elements**: Event delegation for efficient event handling

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling, flexbox, and animations
- **Vanilla JavaScript**: ES6+ features, DOM manipulation, and event handling
- **Intersection Observer API**: For performance-optimized scroll detection

## Key JavaScript Concepts Demonstrated

- Event Delegation: Efficient event handling using event bubbling
- DOM Manipulation: Creating and modifying elements dynamically
- ES6 Features: Arrow functions, const/let, template literals
- Event Listeners: Click, mouseover, mouseout, scroll events
- Event Binding: Using `.bind()` to pass context to handlers
- Intersection Observer: Modern API for detecting element visibility

## Getting Started

1. Clone or download the project
2. Open `index.html` in a web browser
3. No build tools or dependencies required - runs directly in the browser
